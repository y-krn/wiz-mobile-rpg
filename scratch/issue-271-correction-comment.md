## 再検証訂正（最新・前コメントを置換）

前コメントのうち、損益分岐の `52.1%` と B14 以降を受入基準に含めた記述を訂正する。本コメントを #271 の最新結論とする。

結論は次の通り。

- 旧診断の絶対値は現行 main では成立しない。`workshop-unlocked` は「工房解放済み」ではなく、実体が `workshop-empty` / **工房空（旧ID）** だった。
- 主軸は `workshop-complete` / **工房買い切り済み** とする。#385 の分布再測定で run 開始時の最頻状態は complete（56.3%）であり、工房空は参考値に留める。
- `#264` と今回の死因は両立する。通常の罠あり・工房買い切り済みでは罠が支配的だが、#264 の罠 off + support=3 + 全stat+5 + EXP=.25 という極端条件では boss が支配的になる。
- `52.1%` は撤回する。#275 の `30.9%` は、意思決定 EV の定義として撤回しない。
- 受入基準は **B5 と B10 のみ**。B11 以降は母数不足で未確定とする。


旧診断から生き残った結論は、次の3点である。

- 耐性 affix の追加価値は状態回復アイテムで代替される。現行 no-flee 再集計でも抵抗有無の効果は `+0.03`、95% CI `[-0.51,+0.57]`（with 60 / without 514）で、安定した改善とは言えない。
- 逃走追撃の支配は脅威そのものではなく policy 由来。主診断では flee-retaliation が `189/1031` だが、`FLEE_POLICY=never` では `0` になる。
- 直接防御 core は現行 canon でも `0/16`。未実装の直接防御 core を前提にした設計は採用しない。

崩れた結論は、旧 branch の平均到達・生還率などの絶対値、`workshop-unlocked` を工房解放済みと読む前提、逃走追撃を主脅威とする結論、B14〜B16 の壁を受入基準にする結論である。

### 3. #271 の責務境界

罠は #271 の恒久設計対象には含めず、#352 / #369 系の罠ラインへ委譲する。#271 は **非罠の build-dependent combat quality**（通常戦闘、boss、状態異常、特殊 counter）を対象とする。

complete / flee .35 の致命元では、#271 側が対象にできる非罠は通常 `26.4%` + boss `23.6%` = **約50%**。そのうち boss 単独は約24%なので、boss 案だけでは足りない。罠ラインが残り **50.0%** を担当し、両ラインを合わせて初めて今回観測した致命元のほぼ全量をカバーする。#271 単独で #264 の深度目標を達成できるとは報告しない。

境界確認のため、罠側にも scratch 限定の proxy を追加した。`TRAP_POLICY=conservative`、`TRAP_AVOIDANCE_POLICY=ev`、seed と N は同じで、canonical な `resolveFloorTrapEffect` の後段で **床罠の HP damage だけ**を `0.5x` にした。MP drain、alarm、pitfall、罠選択、回避 policy は変えていない。`TRAP_POLICY=disabled` への置換ではない。

### 4. 階別損益分岐（#271 受入基準）

式は #275 と同じ。

```text
BE(d) = ΔM / ((1-r) * (M+ΔM))
```

ここで、Bn を実際に迎えた同一 run 群を使い、

- `M` = Bn 開始時（= B(n-1) 完了時）の**累積素材**の平均
- `ΔM` = 同一 run の `B(n-1) 開始時 → Bn 開始時` の累積素材差分の平均
- `r` = death banking `.3`

とした。前コメントの `52.1%` は、B5 entrant 全体の start 値と、B5 floor 完走者だけの end 値を別母集団で引いた値であり、この定義を満たさない。従って撤回する。

下表は母数を確保するため `FLEE_POLICY=never` を使った現行 main の再集計（seed=271、complete、N=2000）。d の CI は Wilson 95% CI、gap CI は BE を固定した `d CI - BE` であり、M/ΔM の推定誤差は含めていない。

### 6. 限界と成果物

- B10 の受入表は母数確保のため no-flee 診断条件。実プレイ寄り flee .35 では B10 entrant が現行 N で0だったため、actual policy の B10 を確定したとは言わない。
- gap CI は死亡ハザードの二項 CIだけで、報酬側 M/ΔM の誤差や cohort bias は含まない。深層の B11 以降は特に確定値でない。
- trap proxy は HP damage のみで、予兆・検知・MP drain・alarm・pitfall・biome trapSet の全体是正を測っていない。
- 乱数消費順が変わるため絶対値の完全一致は要求せず、同一 seed 内の base / proxy 比較で判断した。
- 今回は scratch 配下の計測コードだけを変更し、ゲーム側 `src/` は変更していない。実装・PR は作成していない。
