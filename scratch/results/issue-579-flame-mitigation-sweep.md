# Issue #579 段階1: 火炎の罠 what-if 掃引

**この掃引は方向と大きさを見るためのもので、この値をそのまま実装の閾値にしない。**
what-if 試算値は実 `src/` 変更後と乱数消費順が異なるため一致しない
（[[sim-override-differs-from-src]]）。段階2（実装）は本結果を見たうえで別途決める。
`src/` は変更していない。

## 結論（要約）

- **`trapGuard` を効かせる**（現行 trapGuard 分布）だけでは、B5F 死亡率は 67.9%→60.7%
  と小幅にしか動かない。単独では折れ点にならない。
- **予告回避は 50%→75% の間に明確な折れ点がある。** 死亡率は 0%=67.9%→25%=58.9%→
  50%=52.6%→**75%=28.7%**→100%=12.5% と、75% 到達で急落する。突破率も 50%=35.5%→
  75%=58.0% と大きく跳ぶ。
- **予告 100% と廃止（ダメージ0）はほぼ同水準**（突破 77.9% vs 83.1%、死亡 12.5% vs
  10.3%）。「踏む前に確実に気づいて避けられる」は事実上の廃止と同じ効果になる。
- **職業差は残る。** trapGuard on で Mage の突破が 0%→43.8% まで動く一方、Fighter は
  30.0%→40.0% と動きが小さい。予告回避は全職に同じ確率で効くため、職業間の相対順位
  （Mage が最も脆い）は各軸でほぼ維持される。

## B5 が関門として残る範囲

#271 の A1 閾値（完成ビルド Q4 の B5 死亡率 ≤30.9%）を「関門として機能する上限」の
参考値として当てはめると、全職合算の B5F 死亡率がこの水準を割るのは **予告回避 75%
以降**（28.7%）。それより低い回避率（trapGuard on / 予告 0〜50%）は死亡率 52.6%〜
67.9% に留まり、関門は強く残る。**予告 75% 超は関門としての機能をほぼ失う方向**であり、
段階2でこの帯を採用候補にするなら別途 60〜75% 区間を細かく振って折れ点を絞り込む
必要がある。

## Priest / Mage の偏り

- **Priest の B5 撤退は全条件で 0.0%。** 予告回避や廃止でも Priest は「撤退」せず
  「突破するか死ぬか」のどちらかに二極化したまま（既存の [[class-baseline-fixed]] の
  傾向を維持）。予告回避が効くのは「発動前に避けて撤退する」経路ではなく、単純に
  発動機会そのものを減らして突破率を押し上げる形。
- **Mage の突破は baseline で 0.0%（N=21, 未確定）** から、trapGuard=on で 43.8%
  （未確定）、予告75%で 70.6%（未確定）まで動く。Mage セルは entrant N が全条件で
  30未満のため、この職単体の効果量は未確定のまま。全職合算の傾向を Mage 個別へ
  外挿しない。

## 追加軸で確認していないこと

- trapGuard と予告回避の**組み合わせ**は未測定（今回は3軸を単独ずつ振った）。段階2で
  組み合わせを採用候補にする場合は別途測定が必要。
- 予告回避 50%〜75% 区間の細かい折れ点位置は未特定（今回の刻みは 25pt）。
