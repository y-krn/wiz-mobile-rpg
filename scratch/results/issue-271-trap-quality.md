## sim 罠方針

`TRAP_POLICY=conservative`、`TRAP_AVOIDANCE_POLICY=ev`。`calculateFloorDisarmEvThreshold` と `calculateFloorTrapAvoidanceEv` は `src/rules/trap_rules.js` を直接呼ぶ実装で、sim側の閾値写経ではないことを確認した。

強度 override は scenario 内の実 affix 保有者だけに適用し、無保有者の bonus/sense は0のまま。方針は強度に追随している。例えば smart の plan は bonus 1x/max現行の `disarm/force/trigger=65928/132433/47669` から bonus 25x/max100 の `71773/132380/49531` へ変化し、sense cap95/start16 の `196440/396555/142234` から cap100/start3 の `196301/396671/142303` へ変化した。avoidance候補/回数も条件ごとに再評価されている。したがって、強度を上げても行動が変わらない sim 欠陥ではない。

## A / B 判定（主状態 `workshop-core-pools`）

### `trapBonus`

- A は現行5xから観測。endpoint は `reachedFloor`、smart の有/なし N=`329/10969`、差=`+0.414 [0.198, 0.631]`、never の有/なし N=`350/10730`、差=`+0.396 [0.180, 0.612]`。両 cure で同符号かつ95% CI非0。
- 5x/max100でも smart=`+0.414 [0.190, 0.638]`、never=`+0.434 [0.197, 0.671]`。1xはCIが0を跨ぎ、A未観測。10x/25xは両 cureでA条件を満たす。
- B は全測定点で未観測。最大のbonus 25x/max100でも対策なし群生存率は smart=`58.1% [57.2,59.0]`、never=`57.3% [56.4,58.3]`で、20%未満に達していない。
- 判定は `A=5x current`、`B=>25x/max100（未観測）`。したがって測定範囲では `A<B` の窓を下限として観測し、Bの位置そのものは未確定。非単調な順位の入れ替わりを knee とは呼ばない。

### `trapSense`

- cap/start の4直交条件を各150,000 run/cellで測定したが、Aは全条件で未観測。
- `cap95/start3` は smart=`+0.35 [0.13,0.57]`、never=`+0.02 [-0.17,0.22]`で cure間の同符号・CI非0を満たさない。
- 上界 `cap100/start3` は smart=`+0.00 [-0.18,0.19]`、never=`+0.22 [0.04,0.40]`で、やはりA条件を満たさない。Bも未観測で、対策なし群は smart=`59.1% [58.6,59.7]`、never=`58.2% [57.6,58.7]`。
- 上界でもA未観測のため、trapSenseの中間強度掃引は打ち切り。これは「効果なし」ではなく、母数を確保した上でA基準を満たす signal が未観測という判定。

## 多重比較・群構成・N設計

- 主状態の formal endpoint tests は bonus `8条件×2 cure×3 endpoint=48`、sense `4×2×3=24`、combined upperの2 affixを含めると84。α=0.05の期待偽陽性数は4.2本。
- 7シナリオ確認は `6条件×7 scenario×2 cure×(bonus/sense/combinedのgroup合計7)×3 endpoint=294` tests相当で、期待偽陽性数は14.7本。全測定を一つの探索的familyとして数える保守的上限は378 tests、期待18.9本。符号が揃わない分離、単発のCI非交差、CIが重なる順位変動はsignal/逆転として扱わない。
- 主状態の entrant率はpilotで約0.2155。pilotで得た最小有群率は trapBonus=`9/487=0.01848`、trapSense=`3/503=0.005964`。目標有群N≥200から `ceil(200/(0.2155×rate))` を計算し、bonusは50,000 run/cell（最終有群N≥308）、senseは150,000 run/cell（最終有群N≥351）、上界は160,000 run/cell（trapSense有群N≥390）とした。
