# Issue #648: 魔力草 craft コスト（魔石片×3）の入手性

## 判定

基準シナリオ「工房空・B1開始」の深度系列では、魔力草の出発 craft 率は
僧侶 18.4–29.6%、魔術師 3.2–8.8% だった。比較対象の同一開始 bank
での craft 可否率は、僧侶で傷薬 98.4–99.2% / 上薬 70.4–89.6% /
祝福の聖水 90.4–99.2%、魔術師で傷薬 99.2% / 上薬 70.4–99.2% /
祝福の聖水 81.6–99.2% だった。

したがって、魔術師では比較対象より明確に低い。僧侶も比較対象の
最低帯の約 0.2–0.33 倍で、同率とは言えない。Issue の判定基準では
「比較対象と同オーダー」とは判定しない。ただし、これは測定結果であり、
この PR では craft コスト・回復量・その他のバランス値を変更しない。

## 条件と測定方法

- 正規の run generator 経由。`src/` の `getAdditionalCraftableCount`、
  `purchaseDepartureCraft`、素材支払い、アイテム効果適用を使用した。
- `N=500 SIM_SEED=231 SIM_CALIBRATION_RUNS=100`、`SIM_PARALLEL` 未指定。
  対象は Fighter / Thief / Priest / Mage、工房状態 7 種、出発素材 bank は
  職業ごとに run 間で維持した。
- 術者は開始 bank で購入可能な MANA_POTION を全量購入する方針を追加した。
  MP が最大値の 55% 以下になった生存中の Priest / Mage が魔力草を使用する。
  比較 3 種は同じ bank に対して `getAdditionalCraftableCount` で可否を測る
  非消費の反実仮想であり、実際には購入していない。
- craft 表の `実/可` は「実際の魔力草購入数 / 同じ bank での可否数」、
  率の `実/可` は対応する run 率。魔石片の内訳は
  `宝箱 / モンスター / その他（クエスト＋残差）`。

## 魔石片の競合

`強化可` と `工房可/run` は、出発クラフト前の同じ `metaMaterials` に対して
`getEnhanceCost` / `purchaseWorkshopNode` を counterfactual に呼んだ値である。
MANA_POTION の購入と同時に強化・工房購入を実行する経路ではない。

- Priest: 武器強化可否 66.4–84.0%、魔石片を使う工房ノード可否数 1.40–1.49/run。
- Mage: 武器強化可否 44.0–91.2%、工房ノード可否数 0.80–1.46/run。
- 実消費（強化 / 工房）は全行 `0.00 / 0.00`。正規 depth sim の AI はこれらの
  sink を購入していないためであり、競合が無いという意味ではない。
- 基準系列の術者では、魔石片は主に宝箱＋モンスター由来。その他は 0.00/run
  付近で、魔石片×3 の craft は bank 内の他用途と明確に同じ素材を取り合う。

## MP 使用閾値の軽い掃引

`N=100 SIM_RUNS=100 SIM_SEED=231 SIM_CALIBRATION_RUNS=20
SIM_SCENARIOS=workshop-empty` を `MANA_POTION_THRESHOLD=0.25 / 0.55 /
0.85` で実行した。小標本の方向確認であり、単発の閾値合わせには使っていない。

| 閾値 | Priest B5 craft率 / 使用 | Priest B20 craft率 / 使用 | Mage B5 craft率 / 使用 | Mage B20 craft率 / 使用 |
| ---: | ---: | ---: | ---: | ---: |
| 0.25 | 28% / 0.40 | 0% / 0.04 | 8% / 0.00 | 0% / 0.00 |
| 0.55 | 28% / 0.56 | 20% / 0.08 | 8% / 0.00 | 4% / 0.00 |
| 0.85 | 28% / 0.64 | 20% / 0.32 | 4% / 0.00 | 8% / 0.04 |

閾値を上げると Priest の使用数は増える傾向だが、craft 成立率の折れ点は
見えない。Mage は到達・生存標本が少なく、使用数も疎である。
