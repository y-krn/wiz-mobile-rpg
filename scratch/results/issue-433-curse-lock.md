# Issue #433: 呪いロックと装備選択方針の上限測定

Closes #433

## 結論

`src/` は変更しなかった。呪い率・呪い検知率・装備選択の各 sweep は、点推定が非単調で CI も重なったため、knee と呼べる採用点を得ていない。従って balance 値も採用していない。

粉無制限、`workshop-core-pools`、B20、N=100 の固定深度測定では、現行の終了時コア装備率は 20.0% [13.3,28.9]、ビルド志向は 23.0% [15.8,32.2]、呪いなしは 13.0% [7.8,21.0]、両方は 19.0% [12.5,27.8] だった。N=100 のため装備数・定着率の条件付き分母が N<30 の場合は未確定であり、順位から結論を出していない。差分は要因で説明できる分の上界で、因果効果ではない。

深度副作用は別の実ラン進行 sim（30 trial × 40 runs = 1,200 runs）で測った。現行・粉無制限を基準にすると、呪いなしは平均到達 B2.99、B5死亡 59.2%、素材EV/時間 0.1203、工房買切(run開始) 13.9%で、現行の B3.02、47.5%、0.1320、18.2%から点推定上は悪化した。CI と他条件の重なりを含め、呪いを消すことの効果とは主張しない。

## SHA変更により取り直しが必要な過去測定

作業中に `origin/main` が `ea5a825` から `e4db2fe` へ進んだため、先に取得した #433 baseline は破棄し、最新 `origin/main` から取り直した。旧 N=100 baseline stdout SHA は `ab4396bf23f802b536bccb8c5dddba0ccb418b8452d7b7ce9ae54b1d2600500a`。最新 commitで同一バイト列になった測定でも、commit provenance が異なるため再取得対象にした。

PR #430 が記録した旧基準（`origin/main=88b8094`、N=500）の全状態 baseline SHA は `32beb6ade66d6972a91deeefeff80765eb52e8a03b00ad7224e112564177677d`。今回 `scratch/sim_depth_material_ev.js` に sweep override と装備方針を追加したため、次の過去測定は旧 stdout SHA を再利用しない。

- `scratch/results/issue-419-identification-default.md`: powder既定、core定着、粉収支、B5/B10、素材EV/時間。
- PR #422 の core 要因分解・`CORE_BLOOD_WAND` 基準測定。
- `scratch/results/issue-410-workshop-variety.md`: 工房状態・出発クラフト・深度比較。
- `scratch/results/issue-292-corrected-results.md` / `issue-292-sim-parallel-progress.md`: depth/workshop の SHA 付き測定。
- `scratch/results/issue-270-real-src-measurement.md`、`issue-271-atk-def-affix-unread.md`、`issue-271-resistance-integrity-progress.md`: 変更 sim の出力を参照する測定。

数値の意味が変わらない可能性があるものも、監査用 stdout SHA は更新が必要。raw dump は commit しない。
