# Issue #483 回復単価 what-if 掃引

## 結論

ゲーム本体の回復量・素材・所持枠は変更していない。現行傷薬15を基準に、実プレイ経路へ上薬 `GREATER_HEAL=40` の能動使用を追加したシミュレーション上で、傷薬の単価だけを掃引した。

- 固定量は15→25〜40で到達性が伸び、50〜60では平均到達floorが頭打ち/反落した。kit 3のknee候補は25、kit 4は40。
- 最大HP比はkit 3で40%、kit 4で35%がknee候補。floor連動はkit 3で `15+4×(floor-1)`、kit 4で `15+5×(floor-1)` が候補だが、固定量ほど単調ではない。
- B10 entrantは不変ではなかった。固定15→40でkit 3は2.4%→7.2%、kit 4は4.8%→5.6%。ただしB10 entrant内訳はN<30の条件が多く未確定。
- #481のP50=3と比較用kit 4は方向を変えず、kit 4は固定15でも平均到達floor 3.75（kit 3は3.30）。
- kit 4では、固定15→40のB5 entrantが戦士8.8%→28.0%、魔術師7.2%→15.2%と伸びた。B5撤退の基準線は戦士90.9%、魔術師88.9%、僧侶1.9%で、#461の「撤退-heavy職ほど効く」という期待と整合するが、僧侶も到達floorは4.38→4.43となった。

これは同一seed sweep上の候補であり、複数比較補正をした採否検定ではない。

- #264の旧4/8/12/16/32掃引は、上薬能動使用と回復単価what-ifを含まないため必須再測定。

- 上薬の工房クラフト反復、所持枠/スタック変更、#264の他レバー、ゲーム本体balance値変更は扱っていない。

- Design Canonはwhat-if測定のみのため更新なし。
