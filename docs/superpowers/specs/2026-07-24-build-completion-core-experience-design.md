# 設計: コア体験「即興ビルド完成」と二相構造

日付: 2026-07-24
状態: 承認済み（設計のみ。実装は別途指示）

## 背景

`.agents/game-design-core-loop.md` は3本柱（深度が問い / push-your-luck /
ラン内ビルド）を掲げるが、simドリブン検証（Issue #231 の
`scratch/sim_depth_material_ev.js`、#237 の深層カーブ検証3周、
`scratch/sim_early_mortality.js` の死因診断）で、いずれの柱も
「プレイヤーが深層まで潜れる」前提の上に立ち、その前提が成立していないことが
判明した（上位論点 #264）。

検証で確定した主な事実:

- Lv1ソロの単発ラン到達は実態 B2、simの楽観条件でも平均 B3-6。
- 深層カーブ（アフィックス予算B6以降拡張＋EXP Lv20拡張）は無効。プレイヤーが
  発動域(Lv11/B6装備)に届かないため、天井を上げても効かない
  （カーブ有無がN=300で完全同値）。
- 成長速度（EXP緩和 ×0.5）は到達性に有効（Lv3.0→4.0、深層生還率倍増）だが、
  「B5撤退が時間効率で最強」は崩れない。到達性と報酬性は別軸。
- **最大の欠落は平均換装1.4回**。ビルドがほとんど組み変わらないまま
  ランが終わっている。

この設計は、上記を踏まえてゲームの**コア体験を再定義**し、既存Issue群
（#231/#234/#236/#237/#264/#267）を主動機の下に再マッピングする。

## コア体験の定式化

> **プレイヤーは即興でビルドを組み、深層でその質を試す。
> 到達深度は「組んだビルドの答え合わせ」。**

決定した設計の芯（ブレインストームで確定）:

| 論点 | 決定 |
| --- | --- |
| 1ランの主動機 | ビルド完成（組み上げる快感） |
| ビルド完成の形 | 即興 — その場で出た拾い物を臨機応変に繋ぐ |
| 「深さ」の役割 | 即興ビルドを試す評価の場（質を深度で問う） |

「即興」であることは既存の重要決定と整合する: 毎ランLv1、毎ラン生成マップ、
未鑑定ドロップ。ビルドは「狙って集める」のでなく「出会って対応する」。
毎ラン違う即興が主快になる。

## 二相構造

1ランは連続的な二相からなる。

```text
ラン開始(Lv1)
  ↓
[前半 = 組む場]  拾い物に豊富に出会い、即興でビルドを繋ぐ。死ににくい。
  ↓
[深層 = 評価の場]  ビルドの質が問われる。弱い即興は死に、良い噛み合わせは通る。
  ↓
到達深度 = 組んだビルドの答え合わせ
  ↓
撤退/死亡 → 素材 → 次ラン(また別の即興)
```

### 境界: 重心B10の連続遷移

固定境界（B5/B6でフェーズを切る）ではなく、**B6〜B10で評価要素が徐々に増す
連続遷移**とし、重心を B10 前後に置く。

- 即興が組み上がるには広い組む場が要る。B5境界では組む場が短く、
  組み上がる前に評価へ出てしまう（換装1.4の実態がこれ）。B10まで組む場を
  確保すれば即興がまとまる。
- 固定壁は「B6から急死」の理不尽になる。連続なら「1個組む→1階深く試せる」
  という漸進的な答え合わせになり、主動機のフィードバックループに合う。
- モバイル短セッション制約は autosave（多セッション前提）で緩和済み。
  前半が長くても分割できる。

トレードオフ: 連続だと「ここが評価の場」の明示感は薄い。ただし即興ビルドの
評価はむしろ漸進的な方がよい（弱いビルドは徐々に苦しくなり、限界で死ぬ＝
答え合わせ）。実装も depth_scaling とドロップカーブの連続再パラメータ化で済み、
固定相分けより自然。

## 二相を実現する機構（A主軸の統合）

到達性・報酬性・供給の3レバーは競合せず、二相の別々の役割を担う。
主動機（即興ビルド）に直撃するのは供給（A）。成長（B）と難度（C）は補助。

### A. 前半 = 組む場（供給）— 主軸

- **装備ドロップを前半で厚くする**。「組み上がった」を感じるには換装が意味ある
  回数起きる必要がある。目標水準: 現状 **換装1.4回 → 4-5回**
  （1ランの前半で数回ビルドを組み替える）。
- **コアアフィックス（ビルドの核16種）を前半で1個は引ける率にする**。現状は
  コアドロップが稀かつ深層偏在で、核なしのランが大半。核があって初めて
  「このコアで戦うランだ」の即興が生まれる。
- **未鑑定（#236）が即興判断の中心**。拾い物＝未鑑定。着る／鑑定する／持つの
  判断こそが即興ビルド。供給が増える＝未鑑定判断が頻発＝主動機の核が回る。
  「持ち歩いて後で鑑定」に支配される #236 の問題は、この文脈で解く。

### B. 組む時間（成長）— 補助

- EXP緩和（#237で実証済み）で、前半に組み上がるLvまで到達させる。B10までに
  ビルドを試せる生存力を持つ。ただしLvは「組む場を生き抜く力」であり、
  ビルドの主役は装備／コア。Bは脇役。

### C. 深層 = 評価の場（難度）

- 深層の脅威を「素のステ勝負」から「**ビルドで対策できる脅威**」へ転換する。
  状態異常・属性・特殊攻撃を、耐性アフィックスやコアで軽減できる形にする。
- 弱い即興（対策のないビルド）は深層で死に、噛み合ったビルドは通る＝評価が
  機能する。現状の「成長不足で死ぬ」から「ビルド質で死ぬ」への転換。

## 検証指標

`scratch/sim_depth_material_ev.js` / `scratch/sim_early_mortality.js` に追加する:

- **換装回数**（ビルドを組めているか）目標4-5。
- **コア装備率**（核を引けているか）目標: 前半で1個。
- **ビルド質 × 到達深度の相関**（良いビルド→深く、が成立するか＝評価の場の
  検証）。
- 既存指標（到達深度・生還率・単位時間EV）は維持。

## Issue 再マッピング

主動機「即興ビルド」の下で、既存Issueの優先順位を組み替える。

- **[新] ビルド供給設計** = 最優先。ドロップ頻度・コア出現率・多様性。
  組む場の生命線。
- **[新 / C] 深層難度の質依存化** = 評価の場。脅威をビルドで対策できる形に
  （depth_scaling ＋ 敵設計）。
- **#236 未鑑定** = 即興判断の中心に昇格。供給文脈で解く。
- **#237 成長速度** = B、補助に格下げ。EXP緩和は有効だが脇役。
- **#231 報酬性（B5最上位）** = 優先度低。主動機と直交。「試さず浅く帰るのが
  得」を防ぐ範囲でのみ関与。
- **#234 シンク** = 供給増で素材経済が動く → 連動して見直し。
- **#267 後衛** = 別軸（ソロ後衛のMP経済）として継続。
- **#264** = 上位論点を「即興ビルド主動機」で再定義。到達性/報酬性の下に、
  供給が最優先レバーとして入る。

## 実装しないこと（YAGNI）

- 固定フェーズ境界（B5で明示的にモードを切る）。連続遷移で足りる。
- ビルドを「狙って集める」仕組み（レシピ・目標ビルド提示）。即興を殺す。
- 到達深度そのものを主スコアにする記録競争寄りの設計。深さは評価の場であって
  目的ではない。
