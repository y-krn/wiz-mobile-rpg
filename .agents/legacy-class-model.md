# Legacy class model

The class-based values referenced by older balance and combat notes are
historical evidence only. The former runtime class-data module was removed by
Issue #1102; current-run characters do not load or consult those values. Use
`.agents/game-logic.md` for the current classless contract.

Old measurements may still mention class names, class passives, or class-axis
comparisons because those runs were recorded before the vNext ownership model.
They must not be copied into current production rules or save migration.
