# Issue #419: 鑑定方針の既定値変更

## 結論

`powder` を `scratch/simulations/sim_depth_material_ev.js` の既定にする。実装側の開始粉、鑑定可能判定、粉の消費、呪いによる装備ロックをシミュレーション側の呼び出し経路で再現しているためである。

`legacy` は実装のモデルではない反実仮想として残す。拾った装備を全て鑑定済み・呪いなしとするため、コード内ラベルから「既定」を削除した。`gamble` も更新候補を即着用する行動反実仮想であり、実装の既定にはしない。

## 実装との対応

| 方針 | シミュレーションの挙動 | 実装との対応 |
| --- | --- | --- |
| `powder` | 粉があり、かつ対象が未鑑定なら鑑定し、粉がなければ未鑑定のまま保持 | `src/rules/identification_rules.js` の `startingPowder` / `identifyCost`、`src/equip.js` の鑑定可否、`src/systems/identification.js` の `identifyEquipment` と `identifyTickets` 消費、`src/rules/identification_rules.js` の `isCurseLocked`、`src/systems/equipment_generation.js` の呪い付与経路に対応 |
| `gamble` | 更新候補を即着用し、未鑑定・呪いのリスクを結果へ反映 | `src/equip.js` の `revealEquipmentOnEquip` を通す行動反実仮想。粉を使う通常の鑑定行動ではない |
| `legacy` | 全装備を鑑定済み・呪いなしとして処理 | 実装外の互換用反実仮想。開始粉・鑑定費用・呪いロックを再現しない |

開始粉は `src/movement.js` の `IDENTIFICATION_BALANCE.startingPowder`（2）から開始し、工房・出発キットで追加される。鑑定は `identifyCost`（1）を消費し、粉不足時は `src/equip.js` の経路で鑑定しない。宝箱は `chestPowderChance`（18%）、戦闘報酬は初回撃破種5体ごとの追加粉、節目商人は `identify_powder` 商品（霊粉2個）である。商人購入は現行シミュレーションに自動購入者がないため、既定計測では `未観測` として別感度分析に分けた（効果なしとは扱わない）。

なお、設計定数 `AFFIX_BALANCE.coreCurseChance`（0.3）は現行の装備生成器から直接参照されず、実測経路は `IDENTIFICATION_BALANCE.coreCurseBonus`（0.08）である。これは実装側の別課題候補として記録し、本 issue の PR では `src/` を変更していない。

## 再現条件と出力

`origin/main`（`30da11f899b72469b9eea4afd68a78ef668a8ed6`）で旧既定を同じ条件で取り直し、作業ブランチでも同じ seed・環境を使用した。工房単独ではなく、7シナリオを同時に実行している。

```sh
SIM_PRESET=balance-main SIM_SEED=231 SIM_RUNS=1000 SIM_CALIBRATION_RUNS=1000 IDENTIFICATION_POLICY=legacy node scratch/simulations/sim_depth_material_ev.js
SIM_PRESET=balance-main SIM_SEED=231 SIM_RUNS=1000 SIM_CALIBRATION_RUNS=1000 IDENTIFICATION_POLICY=powder node scratch/simulations/sim_depth_material_ev.js
```

出力 SHA-256 は次のとおり。

## 符号が変わる過去結論

同じ方針内のシナリオ順位を旧既定と新既定で比較した結果、次が反転した。

- **素材 EV/時間の最高シナリオ**: 旧は「血杖・深層呪文」 `.0898`、新は「買い切り」 `.0963`。
- **平均到達階のコアプール対買い切り**: 旧は買い切り `2.14` > コアプール `2.10`、新はコアプール `2.14` > 買い切り `2.11`。
- **血杖対血杖・深層呪文**: 旧は深層呪文が到達階 `2.13 > 2.06`、EV/時間 `.0898 > .0863`。新は血杖が到達階 `2.09 > 2.06`、EV/時間 `.0875 > .0787`。
