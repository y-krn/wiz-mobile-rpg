# Issue #536 / #264 closure audit

## 結論

**#264は閉鎖可。** オーナー判断の受入目標は「4職合算 B10 entrant ≥10%」。現行基準線は
**3,055/12,000 = 25.46%**、職別も戦士28.1%・盗賊19.2%・僧侶27.2%・魔術師27.3%で、
4職すべて19%以上。B10を直接測れる状態は成立。

ただし、これは品質基準をB10へ移す意味ではない。#510現行再測定でA1/A3が不成立のため、
完成ビルド・core個数の受入基準はB5代理を維持する。#264の到達性目標と#510の品質estimandを分離する。
