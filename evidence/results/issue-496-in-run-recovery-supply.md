# #496 ラン内回復供給 測定結果

## 結論

既存経済のラン内購入だけでは、到達性は動くが深度を大きくは変えない。持込3本のみ相当（N=0/H=16/source）は平均到達floor **3.616 [3.409–3.823]**、B5 entrant **22.4% [19.0–26.3]**、B10 entrant **5.4% [3.7–7.7]**、生還率 **40.4% [36.2–44.8]**。商人購入を最大にした測定点（N=8/H=20/source）は **3.802 [3.551–4.053]**、B5 entrant **23.8% [20.3–27.7]**、B10 entrant **7.2% [5.2–9.8]**で、点推定差は平均floor **+0.186**、B5 **+1.4pt**、B10 **+1.8pt**に留まる。

したがって判定は **深く潜る到達性を目的にするなら設計追加が要る**。既存の商人経路は回復を **0.768本/run** 増やすが、各条件は独立runであり単調な因果差としては扱えない。宝箱回復薬を+25%する反実仮想は B5 **57.2%**、B10 **30.8%**まで動くが、これはゲーム側に未採用の設計追加である。今回の結論は、まず既存経済の商人購入を実装上の選択肢として扱い、別レバーを採用するなら別の設計・canon判断で測る、である。

## 7. 所持枠20による拾得阻害

このrawで直接観測できるinventory_fullは商人購入の失敗だけで、宝箱・素材・装備の拾得拒否を独立カウントしていない。したがって「拾得阻害なし」とは断定できず、**拾得阻害は未測定**とする。

観測上、N=8/H=20/sourceでは終了inventory slots **5.686 [5.312–6.060]**、傷薬商人のinventory_fullは **10回 / 500run**（失敗run率 1.8% [0.9–3.4]）、剛力の薬はinventory_full **22回**、状態回復薬は **6回**だった。所持枠20が商人競合を起こす実測はあるが、拾得への波及は次回、拾得拒否カウンタを追加して測る必要がある。

## 8. 測定限界

- 40条件は同一seedの条件間paired比較ではなく、条件indexをseedへ反映した独立run。Nを増やしたときの差は点推定であり、因果効果や単調性を主張しない。
- B5/B10のentrantは全run分母、突破/死亡/撤退はentrant分母。N<30のendpointは*で未確定。B10の条件付きendpointと職業別endpointには未確定が多い。
- 出発kitは3本固定で、開始在庫・プレイヤーの購入判断・職業間の動的な意思決定は掃引していない。商人順序は傷薬→剛力の薬。逆順、翼購入、別の価格やbank率は未測定。
- 宝箱+25%はsim専用what-if。ゲーム本体の価格、宝箱抽選、所持枠canon、採用balanceは変更していない。
- 素材EV/時間は bankedMaterials / timeCost。素材型別収支は終了run残高・商人消費・bank残高であり、拾得阻害の損失は含まない。
- source別の入手・消費値はaggregatorが保持したper-run平均で、率としてのWilson CIを持つのは枯渇率・endpoint・生還率・商人失敗run率。平均値のCIは正規近似。
- raw dump自体はContext Hygieneに従いコミットせず、この要約に判定に必要な数値を全て転記した。
