# Issue #534 魔術師死亡律速 測定結果

## 結論

- 現行魔術師 B5死亡率: 15.8% [12.3,20.2; N=322]。死亡時直前被害源最多: 通常戦闘。
- killHeal 発動は魔術師 6.77 [5.58,7.97; N=500]回/run、実回復 23.25 [19.27,27.23; N=500]HP/run。死亡runの発動0率 34.7% [28.0,42.0; N=173]。
- 死亡run直前1ターン被害 9.16 [8.40,9.92; N=168]、最大HP比 0.448 [0.398,0.498; N=168]、被害hit数 1.16 [1.10,1.22; N=168]。
- 採用: Mage 初期HP+2 / level HP成長+1（初期HP21、成長4..6）。採用後のN=3000基準線は `evidence/results/issue-461-baseline.md`。

## 採用判定（レビュー対応）

- `killHeal+10` はB10到達率26.2% [22.5,30.2; N=500]まで改善する有効な候補。初期仮説は「`killHeal`増量では解けない」から「撃破前死亡には効かない」へ限定修正する。死亡runの34.7% [28.0,41.9; N=176]は発動0回だが、撃破後まで生き残るrunでは回復が累積し、`killHeal+6/+8/+10`でB10到達率14.8%/21.0%/26.2%と単調に伸びた。
- `killHeal+10`の長所は深度（平均floor7.06 [6.68,7.44; N=500]）とB10到達、短所はB5死亡13.6% [10.5,17.5; N=360]、戦闘55.39 [49.73,61.06; N=500]turn/run、素材EV/時間0.1588 [0.1506,0.1670; N=500]。初期HP+2/成長+1はB5死亡10.3% [7.7,13.8; N=377]、平均floor6.11 [5.86,6.36; N=500]、43.22 [39.98,46.46; N=500]turn/run、素材EV/時間0.1755 [0.1678,0.1832; N=500]で、深度以外の主指標が優位。
- 両候補ともMage-only overrideで、他3職B10 entrant差は戦士/盗賊/僧侶すべて0.0pt。`killHeal+10`は汎用support基準値2、Fighter+2、Mage+4に対して突出したclass passive値（Mage現行の2.5倍）となる。初期HP+2/成長+1は撃破triggerを増幅せず、撃破前から効く静的耐久で死亡律速を直接緩和し、将来職のHP成長設計にも適用しやすい。このため採用点は変更せず、`killHeal=4`を維持する。
