# Issue #948: structure-driven terrain evidence

Date: 2026-08-29

Source: `6198e43b98232da41257364b225acd7fd28aaae3`

The four forced profiles below use `generateRandomMap` with 48 seeds, a 24x24
map, and room range `[2, 3]`. The profile selects the floor's
`structureType`; the selected type then changes maze tuning and room carving.
The aggregate metrics are generated from the connected graph before one-way
passages and secret doors are added.

| structureType | cycles | alternative path rate | junctions | corridor ratio | open-area cells |
| --- | ---: | ---: | ---: | ---: | ---: |
| corridor | 4.27 | 0.215 | 15.52 | 0.763 | 9.75 |
| loop | 10.33 | 0.404 | 36.19 | 0.568 | 15.13 |
| hub | 12.38 | 0.495 | 38.42 | 0.489 | 18.00 |
| openArea | 15.96 | 0.557 | 41.10 | 0.439 | 22.31 |

Corridor has the highest corridor ratio and lowest alternate-path rate; Loop
has substantially more cycles and alternate paths; Hub has concentrated
junctions; Open area has the largest open-area footprint. The same seed and
floor remain deterministic, and the unit suite checks that each forced map is
connected.

Representative 24x24 maps use `#` for closed cells, `.` for passages, `U` for
stairs-up, and `D` for stairs-down. Reproduce with the forced profiles and
seed prefix `ISSUE-948-EVIDENCE-`.
