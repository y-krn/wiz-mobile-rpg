# Same-user competitive comparison template

Compare observable player-facing behavior for the same intended user. Product
names are record data, not protocol enums.

- Protocol version: `1.1`
- Comparison ID: `<YYYY-MM-DD-NN>`
- Exact source SHA for target: `<40-character SHA>`
- Target build/version: `<version>`
- Benchmark product/version: `<current product/version>`
- Platform/device conditions: `<matched conditions>`
- Date/availability check: `<YYYY-MM-DD and source>`
- Goal ID: `<start-to-gameplay|combat-primary-action|target-cancel-reselect|loot-equipment-understanding|inventory-pressure|high-loss-decision|result-next-attempt>`
- Golden Journey/task: `<journey ID / TASK-XX>`
- Equivalent goal: `yes` / `no`
- Outcome: `success` / `success_with_friction` / `blocked` / `not_applicable` / `not_observed`
- Friction codes: `<bounded codes or none>`
